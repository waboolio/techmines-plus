# Techmines Plus 0.16.0

- Reforged item tooltips now show a compact coloured tier letter: S, D, M, L, E, R, U or C.
- Uses exact server reforge rarity metadata first, with full-bonus matching against 21 reforges and 168 screenshot-confirmed tiers as a fallback. Includes Swift and Itchy penalties. Unknown cases stay unmarked.
- Item names, stats and server-side components remain unchanged.

Choose one jar matching Minecraft 26.3 or 26.2. Requires Java 25, Fabric Loader 0.19.5+, and Fabric API matching your Minecraft version. Disable older Techmines jars.
