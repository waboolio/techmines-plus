# Techmines Plus 0.13.1

- Vendor prices, talismans, elytra and totals now use consistent compact units with exactly two decimal places.
- Fixed floating point import residues in Palmwood Sword V, Amberite Sword V and Heliodor Pickaxe I; these prices now contribute to their resource totals.
- Keeps genuine missing-unit warnings and estimate markers. No workbook prices are changed.

Choose one jar matching Minecraft 26.3 or 26.2. Requires Java 25, Fabric Loader 0.19.5+, and Fabric API matching your Minecraft version. Disable older Techmines jars.
