# Techmines Plus 0.10.0

- Added Heal (/heal), Accessory Bag (/bag) and Overclock (/oc) buttons.
- Bag replaces Fly in the compact inventory row. Fly moves to the left beside the chestplate; Heal sits below it.
- Overclock replaces Trash on the top bar. Trash moves just to the right of the hotbar.
- All ten command shortcuts are available in a two-row K menu.
- Open /bag and /oc once to capture the exact server menu-item icons; the cache stays local. Temporary vanilla icons are shown until then.
- Vendor data, world buttons and totals are retained.

Choose the Minecraft 26.3 or 26.2 jar attached below. Requires Java 25, Fabric Loader 0.19.5+ and matching Fabric API. Enable only one Techmines edition/version.
