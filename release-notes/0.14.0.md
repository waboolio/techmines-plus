# Techmines Plus 0.14.0

- Click a sender name in Techmines chat to insert @name into your current chat draft at the cursor. Open chat first, then click the name and finish your message.
- Preserves existing chat formatting, message links and unfinished drafts. No message is sent until you send it.

Choose one jar matching Minecraft 26.3 or 26.2. Requires Java 25, Fabric Loader 0.19.5+, and Fabric API matching your Minecraft version. Disable older Techmines jars.
