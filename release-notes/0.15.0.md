# Techmines Plus 0.15.0

- Right-click vault buttons to set custom names, reset them, or cancel. Left-click still opens the same numbered vault.
- Vault labels persist locally per Minecraft account and are shared between editions in the same instance.
- Added a searchable, paginated Players screen with ping and count, using the full server-listed roster beyond the vanilla Tab display's 80-player cap. Access it from the K menu or the player-head icon below Heal. Players the server does not report remain unavailable.

Choose one jar matching Minecraft 26.3 or 26.2. Requires Java 25, Fabric Loader 0.19.5+, and Fabric API matching your Minecraft version. Disable older Techmines jars.
