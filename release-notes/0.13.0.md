# Techmines Plus 0.13.0

- Vendor Info now has its own row above the inventory shortcuts.
- Shortcut row order: Overclock (/oc), Shop (/shop), Shards (/shards), Skill Tree (/skilltree). Skill Tree uses an oak sapling icon and is also available in the K menu.
- PvP moved to the side column above Fly.
- The vendor row adapts to keep both rows visible at the minimum GUI height.

Choose one jar matching Minecraft 26.3 or 26.2. Requires Java 25, Fabric Loader 0.19.5+, and Fabric API matching your Minecraft version. Disable older Techmines jars.
